# 悬城守卫 Hoverhold

2D 国风手绘守城策略游戏。七方山河，每章三关，并提供无尽守城。

## 在线试玩

[GitHub Pages](https://zhangwb798.github.io/hoverhold-defense/)

## 操作

- 悬停树木或矿石采集资源，单棵树提供 150 木材。
- 建造兵营并悬停招兵；点击空地集结，指挥将领与军队守城。
- 战后金币用于局外升级，关卡逐步解锁。
- 在设置中调整画质、分辨率与画面尺寸。
